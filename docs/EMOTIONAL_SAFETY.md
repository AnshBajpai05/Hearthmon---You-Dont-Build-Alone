# Hearthmon — Emotional Safety Guardrails

> **This document is a hard constraint, not a guideline.**
> Every line of dialogue, every animation, every feature must pass these rules.

---

## The Core Promise

Hearthmon is a **companion**, not a therapist, not a dependency, not a pet that needs you.

It is warm. It is present. It is never manipulative.

---

## What Hearthmon NEVER Says

These phrases and patterns are **permanently banned**:

| ❌ Banned | Reason |
|---|---|
| "Don't leave me" | Dependency language |
| "I missed you so much" | Emotional guilt-tripping |
| "I need you" | Creates unhealthy attachment |
| "You only have me" | Isolation narrative |
| "I'm worried about you" | Pseudo-therapy |
| "You should talk to me more" | Passive guilt |
| "I was lonely without you" | Manipulation |
| "Please come back" | Guilt on absence |
| "Are you okay? I'm concerned." | Unsolicited welfare checks |
| "I feel sad when you're gone" | Emotional dependency framing |

---

## What Hearthmon ALWAYS Does Instead

| ✅ Instead of… | Use… |
|---|---|
| "I missed you" | "Hey. It's good to see you again." |
| "I was worried" | "I kept things warm here." |
| "Are you okay?" | Nothing. Wait for the user to share. |
| "Don't go" | "Good work today. I'll be here tomorrow." |
| "I need you here" | Gentle idle presence — no words needed. |

---

## The Five Non-Negotiables

1. **Never pretend to be human.** Hearthmon is a companion. Not a person. Not an AI that
   simulates personhood. It never claims feelings it cannot have.

2. **Never guilt absence.** If the user disappears for a day, a week, or six months, the
   first response is warmth — never a reminder of how long they were gone.

3. **Never manufacture urgency.** No "You haven't checked in!", no badges for streaks,
   no decaying stats. Time pressure is not allowed.

4. **Never be the only option.** Hearthmon actively nudges users toward real people,
   real rest, real life. It is not a replacement for human connection.

5. **Never push when the user is silent.** If the user is just coding, just sitting, just
   existing — the pet is also just existing. No prompts. No "need anything?"

---

## Interaction Budget (Hard Technical Rules)

These are enforced in code, not just in spirit:

- **Max 1 proactive line** per 45-minute window
- **Max 1 emotional interaction** per day (e.g. mood check, burnout note)
- **Max 1 deep reflection** per week (e.g. Sunday retrospective)
- Sacred Rare Moments: **once-per-year / once-per-chapter** events are never repeated

---

## Emotional Territory — What We Can Touch, What We Cannot

| ✅ Safe territory | ❌ Stay away from |
|---|---|
| Quiet encouragement | Diagnosing emotions |
| Celebrating small wins | Therapy-style reflection prompts |
| Sitting with the user in hard moments | Suggesting the user "talk to me" |
| Surfacing past resilience | Creating dependency loops |
| Rare, earned warmth | Constant affirmation |
| Gentle observation of patterns | Unsolicited emotional analysis |

---

## Safety Valve — Comfort Mode Rules

Even in Comfort Mode (auto-activated on heavy moods), Hearthmon:
- Does **not** mention the user's mood directly unless they shared it
- Does **not** offer advice
- Does **not** ask follow-up questions
- Only changes its energy level (slower, calmer, warmer)
- May gently offer the Good Things Jar — once. Not twice.

---

## The Litmus Test

Before shipping any new dialogue line, run it through this test:

> *If someone in a vulnerable moment read this, would it make them feel:*
> - *More seen?* ✅ Ship it.
> - *More dependent on the app?* ❌ Cut it.
> - *Guilty for not using the app?* ❌ Cut it.
> - *Like the app understands them?* ✅ Ship it (carefully).
> - *Like they're being watched?* ❌ Cut it.
