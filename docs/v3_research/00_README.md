# V3 Research — discovery only

> Started 2026-06-18. This folder is **research, doctrine, and architecture — never a backlog.**
> No code, no tickets, no UI, no schema. While **V2 is validated with real users**, **V3 matures
> on paper.** The decision to write any V3 code comes *only* after V2 has real feedback **and**
> this doctrine is crystal clear.

## The two phases run in parallel

```
V2 Validation Phase   →  collects reality (real users, real feedback)
V3 Discovery Phase    →  matures the doctrine (these files)
```

## The one rule

No file here **concludes the soul.** They hold questions, candidates, tensions, and sources.
When a question genuinely closes — by evidence or a real decision, never by a good conversation —
it *graduates* out of here into [HEARTH_SHELF.md](../HEARTH_SHELF.md) (the law). Until then it stays open.

> *Reveal the soul by what people place — don't declare it with a button.* That principle governs
> the research too: we are here to **observe and understand**, not to prescribe.
